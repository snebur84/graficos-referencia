01. Séries Temporais Gráfico de Linhas

Gráfico de Linhas: Quando e Por Que Usar?

Evolução Temporal

Ideal para rastrear mudanças contínuas ao longo de dias, meses ou anos.

Identificação de Tendências

Destaca sazonalidades, picos, quedas bruscas e pontos de inflexão.

Comparação de Séries

Permite comparar múltiplas linhas (séries) em uma mesma escala vertical.

Aplicações típicas: Histórico de vendas, cotações de ações, variação de temperatura e contagem de usuários ativos.
01. Séries Temporais Código Python

Como Criar com Seaborn & Matplotlib

import matplotlib.pyplot as plt
import seaborn as sns

sns.set_theme(style="whitegrid")
df_flights = sns.load_dataset("flights")

fig, ax = plt.subplots(figsize=(10, 4))

# Criando o gráfico de linhas
sns.lineplot(
    data=df_flights[df_flights["year"] == 1960],
    x="month", y="passengers",
    marker="o", color="#2563eb", linewidth=2, ax=ax
)

ax.set_title("Evolução do Número de Passageiros (1960)", fontweight="bold")
ax.set_xlabel("Mês")
ax.set_ylabel("Total de Passageiros")

plt.tight_layout()
plt.show()

02. Comparação Categórica Gráfico de Barras

Gráfico de Barras: Quando Utilizar?

Comparação Direta

Compara métricas numéricas (ex: média ou soma) entre categorias discretas.

Agrupamento Secundário

Permite dividir categorias principais em subgrupos usando o parâmetro hue.

Ranking e Ordem

Facilita ordenar itens do maior para o menor para destacar líderes e retardatários.

Dica: Se os nomes das categorias forem longos, inverta os eixos para criar barras horizontais.
02. Comparação Categórica Código Python

Como Criar com Seaborn & Matplotlib

import matplotlib.pyplot as plt
import seaborn as sns

df_tips = sns.load_dataset("tips")
fig, ax = plt.subplots(figsize=(8, 4))

# Gráfico de barras agregando média do valor total
sns.barplot(
    data=df_tips, x="day", y="total_bill",
    hue="sex", palette="Set2", errorbar=None, ax=ax
)

ax.set_title("Média do Valor da Conta por Dia e Gênero", fontweight="bold")
ax.set_ylabel("Média da Conta ($)")
ax.legend(title="Gênero")

plt.tight_layout()
plt.show()

Tratamento de Rótulos

Evite categorias com nomes excessivamente longos ou formate os dados invertendo a orientação (y="categoria").

03. Correlação & Relação Código Python

Como Criar com Seaborn & Matplotlib

import matplotlib.pyplot as plt
import seaborn as sns

df_tips = sns.load_dataset("tips")
fig, ax = plt.subplots(figsize=(8, 4))

# Scatter plot + Linha de Regressão
sns.scatterplot(
    data=df_tips, x="total_bill", y="tip",
    hue="time", alpha=0.8, ax=ax
)
sns.regplot(data=df_tips, x="total_bill", y="tip", scatter=False, color="gray", ax=ax)

ax.set_title("Relação entre Valor da Conta e Gorjeta", fontweight="bold")
plt.tight_layout()
plt.show()

04. Distribuição Numérica Histograma & KDE

Histograma & KDE: Quando Utilizar?

Frequência de Dados

Mostra como as observações se distribuem em intervalos contínuos (bins).

Densidade Suave (KDE)

O KDE (Kernel Density Estimation) calcula uma estimativa da função de probabilidade contínua.

Análise de Assimetria

Permite checar se a distribuição é normal, simétrica ou possui caudas longas.

04. Distribuição Numérica Código Python

Como Criar com Seaborn & Matplotlib

import matplotlib.pyplot as plt
import seaborn as sns

df_tips = sns.load_dataset("tips")
fig, ax = plt.subplots(figsize=(8, 4))

# Histograma com curva KDE (Kernel Density Estimation)
sns.histplot(
    data=df_tips, x="total_bill",
    bins=15, kde=True,
    color="#2563eb", ax=ax
)

ax.set_title("Distribuição dos Valores das Contas", fontweight="bold")
plt.tight_layout()
plt.show()
04. Distribuição Numérica Padronização de Dados

Como Padronizar os Dados para Histogramas

A quantidade de bins é crucial: poucos bins escondem a forma, muitos geram ruído.

Normalização da Escala

Utilize stat="density" ou stat="percent" para comparar amostras de tamanhos diferentes.

05. Variabilidade & Outliers Boxplot & Violin

Boxplot & Violin Plot: Quando Utilizar?

Resumo Estatístico

Exibe Mediana, Quartis ($Q_1$ e $Q_3$) e a amplitude IQR em uma caixa.

Identificação de Outliers

Valores discrepantes fora dos "bigodes" (whiskers) são destacados individualmente.

Violin: Densidade Categórica

O Violin plot adiciona a estimativa de densidade contínua ao redor da caixa estatística.

05. Variabilidade & Outliers Código Python

Como Criar com Seaborn & Matplotlib

import matplotlib.pyplot as plt
import seaborn as sns

df_tips = sns.load_dataset("tips")
fig, ax = plt.subplots(figsize=(8, 4))

# Boxplot por categoria (caixa IQR e mediana)
sns.boxplot(
    data=df_tips, x="day", y="total_bill",
    palette="Pastel1", ax=ax
)

ax.set_title("Dispersão do Valor da Conta por Dia", fontweight="bold")
plt.tight_layout()
plt.show()
05. Variabilidade & Outliers Padronização de Dados

Como Padronizar os Dados para Boxplot

Eixo Categórico x Contínuo

Defina a variável categórica em X e a numérica em Y. Não necessita de normalização prévia.

Divisão no Violin Plot

No Violin plot, ao comparar subgrupos binários, utilize split=True para otimizar a visualização.

06. Matrizes & Correlação Heatmap

Heatmap: Quando Utilizar?

Matrizes 2D

Exibe dados tabulares 2D (Bidimensionais) através de gradientes de cor.

Matriz de Correlação

Visualização rápida de coeficientes de correlação entre dezenas de colunas numéricas.

Densidade Cruzada

Ideal para tabelas de pivô (pivot_table) com duas variáveis nas margens.

06. Matrizes & Correlação Código Python

Como Criar com Seaborn & Matplotlib

import matplotlib.pyplot as plt
import seaborn as sns

df_tips = sns.load_dataset("tips")
matriz_corr = df_tips.corr(numeric_only=True)

fig, ax = plt.subplots(figsize=(8, 4))

# Heatmap da matriz de correlação 2D
sns.heatmap(
    matriz_corr, annot=True, fmt=".2f",
    cmap="coolwarm", linewidths=.5, ax=ax
)

ax.set_title("Matriz de Correlação Numérica", fontweight="bold")
plt.tight_layout()
plt.show()
06. Matrizes & Correlação Padronização de Dados

Como Padronizar os Dados para Heatmap

Paletas divergentes (coolwarm) para correlação e sequenciais (Blues, viridis) para volumes acumulados.

07. Proporção & Composição Gráfico de Pizza

Gráfico de Pizza: Quando Utilizar?

Composição Relativa

Ideal para mostrar a participação percentual das partes que compõem um total ($100\%$).

Poucas Categorias ($\le 5$)

Funciona bem apenas quando há de **2 a 5 categorias** bem diferenciadas.

Variação de Rosca (Donut)

Adicionar um círculo no centro (wedgeprops) melhora a estética e reduz o ruído visual.

Atenção: Evite utilizar gráficos de pizza quando houver mais de 5 categorias ou quando os valores forem muito próximos. Nestes casos, prefira um gráfico de barras.
07. Proporção & Composição Código Python (Matplotlib)

Como Criar com Matplotlib

import matplotlib.pyplot as plt
import seaborn as sns

valores = [40, 30, 20, 10]
categorias = ["Produto A", "Produto B", "Produto C", "Outros"]
cores = sns.color_palette("Set2")

fig, ax = plt.subplots(figsize=(6, 6))

# Gráfico de Pizza / Rosca nativo do Matplotlib
ax.pie(
    valores, labels=categorias, autopct="%1.1f%%",
    startangle=90, colors=cores,
    wedgeprops=dict(width=0.6, edgecolor="white") # Rosca
)

ax.set_title("Distribuição de Vendas por Categoria", fontweight="bold")
plt.tight_layout()
plt.show()
07. Proporção & Composição Padronização de Dados

Como Padronizar os Dados para Pizza

Agrupamento e Consolidação

Agrupe categorias menores em um grupo genérico ("Outros") com df.groupby() se houver mais de 5 itens.

Soma Total = 100%

Garanta que a soma das fatias represente a totalidade dos dados sem sobreposição de categorias.

Resumo & Conceitos

Glossário de Siglas e Boas Práticas

Significado das Siglas Utilizadas

KDE (Kernel Density Estimation): Estimativa de Densidade de Kernel, uma função contínua que suaviza a distribuição dos dados.
IQR (Interquartile Range): Intervalo Interquartil ($Q_3 - Q_1$), a amplitude ocupada pelos 50% centrais dos dados no Boxplot.
NaN (Not a Number): Representação para valores nulos ou ausentes em tabelas e DataFrames.
2D (Bidimensional): Dados dispostos em formato de matriz com duas dimensões (linhas e colunas).
DPI (Dots Per Inch): Pontos por polegada, parâmetro que define a resolução da imagem ao exportar (dpi=300).
Tidy Data: Formato padronizado de dados onde cada coluna representa uma variável e cada linha uma observação.

1. Tidy Data

Variáveis em colunas e observações em linhas.

2. Rótulos Claros

Título, unidades ($) e legenda visíveis.

3. Paleta com Contraste

Cores que diferenciam grupos claramente.

4. Layout Limpo

Finalize com plt.tight_layout().
